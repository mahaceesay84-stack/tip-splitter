# 🪙 Tip Splitter (Gambian Dalasi)

A clean, responsive tip calculator and bill splitter localized for **Gambian Dalasi (D)** with zero-float integer math.

🔗 **Live Demo:** [mahaceesay84-stack.github.io/tip-splitter](https://mahaceesay84-stack.github.io/tip-splitter/)

---

## ✨ Features
- **Live Computations:** Updates tip, total, and per-person breakdown in real-time as you type.
- **Preset & Custom Tips:** 5 quick-select preset percentages plus a custom percentage field.
- **Integer Math Precision:** Calculates in *bututs* (cents) to avoid floating-point rounding errors.
- **Fair Remainder Handling:** Intelligently identifies and displays uneven split remainders when bills don't divide equally.
- **Input Validation:** Clear validation states for zero or negative party sizes.
- **Responsive Design:** Mobile-first, fully responsive layout built with custom CSS.

---

## 🛠️ Tech Stack
- **HTML5** — Semantic structure and accessible form inputs
- **CSS3** — Custom properties, flexbox/grid layout, and responsive breakpoints
- **Vanilla JavaScript** — Real-time event handling, integer math, and DOM manipulation
